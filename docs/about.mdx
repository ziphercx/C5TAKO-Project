# รู้จัก zipher

zipher คือพื้นที่รวมเครื่องมือและความรู้ด้าน **cybersecurity, hardware และการทดสอบระบบ** สำหรับคนที่อยากเรียนรู้ ลงมือทดลอง และพัฒนาทักษะของตัวเองให้มากขึ้น

เราออกแบบทั้งอุปกรณ์ เฟิร์มแวร์ เอกสารประกอบ และช่องทางชุมชนให้ใช้งานต่อกันได้ ตั้งแต่เริ่มต้นทำความรู้จักอุปกรณ์ ไปจนถึงการทดลองในสภาพแวดล้อมที่ควบคุมได้

<Info>

เครื่องมือของ zipher ควรใช้กับอุปกรณ์ของตัวเอง หรือระบบที่ได้รับอนุญาตอย่างชัดเจนเท่านั้น

</Info>

## ใช้งานอย่างรับผิดชอบ

zipher ทำเครื่องมือที่รองรับการทดสอบทั้งเชิงรุก (Offensive) และเชิงรับ (Defensive) เพื่อการเรียนรู้ การวิจัย และการทดสอบความปลอดภัย ผู้ใช้ต้องใช้งานเฉพาะกับระบบ อุปกรณ์ หรือเครือข่ายของตนเอง หรือที่ได้รับอนุญาตอย่างชัดแจ้ง และควรตรวจสอบกฎหมายหรือนโยบายของระบบก่อนทำการทดสอบทุกครั้ง

<Warning>

ห้ามนำอุปกรณ์หรือคำสั่งไปใช้เพื่อโจมตี รบกวน เข้าถึง ดักรับข้อมูล หรือทดสอบระบบของผู้อื่นโดยไม่ได้รับอนุญาต รวมถึงการละเมิดหรือคุกคามทางไซเบอร์ทุกรูปแบบ ผู้ใช้ต้องรับผิดชอบต่อการใช้งานของตนเอง และ zipher หรือผู้พัฒนาไม่รับผิดชอบต่อความเสียหายหรือผลกระทบจากการนำเครื่องมือไปใช้โดยไม่ได้รับอนุญาต ผิดกฎหมาย หรือผิดวัตถุประสงค์

</Warning>
